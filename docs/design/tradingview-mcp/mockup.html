TradingView

Strategy Lab market data (MCP)

Not configured

Connect a TradingView MCP server so the Strategy Lab pulls OHLCV price data from TradingView before falling back to the free public providers.

Enter the URL of your TradingView MCP server and an optional bearer token. The Strategy Lab calls the MCP get_ohlcv tool to fetch price bars.

https://your-tradingview-mcp.example.com/mcp
Streamable-HTTP JSON-RPC endpoint of the TradingView MCP server.
••••••••
Sent as a Bearer token to the MCP server. Stored encrypted.
get_ohlcv
MCP tool the Strategy Lab calls for price bars. Defaults to get_ohlcv.
Enable TradingView data source

After saving with the toggle on, the status chip flips to ✓ Connected and a Disconnect button appears (Screen 4).
