# agent_cognition

A reusable **cognition substrate** for agents generated by the Agentic AI team — turning a
bare LLM wrapper into something with the faculties of a reasonable thinking person:

- **Memory layer** — time-partitioned episodic events with idempotent day → week → month →
  year rollups and budget-aware retrieval.
- **Rules engine** — hybrid `advisory` (prompt-injected) + `enforced` (deterministic
  pre/postcondition) rules, learned from memory and **proposed for human approval** before
  they take effect.
- **Tools layer** — per-agent tool binding composed from the existing tool/integration
  registries and executed via the shared tool loop; every tool call feeds memory.

Cognitive state lives in the long-lived **platform Postgres** (namespaced by `agent_id`),
never in the ephemeral per-agent sandbox. Agents consume an injected `cognition` block on
invoke and emit a `cognition_writeback` on return, so sandboxed agents never need direct
store access.
